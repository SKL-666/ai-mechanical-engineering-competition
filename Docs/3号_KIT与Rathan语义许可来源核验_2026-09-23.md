# KIT 与 Rathan：动作语义、使用条件及来源核验

核验日期：2026-09-23。范围为当前保留的 KIT 304 段挖掘机 MP4 和 Rathan v7 的100张 `Excavator - Idle` 图片。本轮只读取来源、标注和媒体，生成审计证据；**未改原5类、现有映射配置、训练输入/划分或 v1/v2 实验结果，也未联系发布者或视频作者。**机器可读的[使用门槛](../derived/supplemental_source_audit/use_gate.json)与本文一致。

## 决定

| 来源 | 语义与重复核验 | 目前可做 | 尚未放行 |
|---|---|---|---|
| **KIT** | Digging→Load Bucket、Dumping→Dump、Hauling/Swinging→同一 Swing Bucket **仍为暂定映射**；抽查支持动作方向，未逐条证明304段均正确。内部 train/val 有近乎相同画面跨划分，不能用于独立验证。 | 保留原件和既有本地研究对照，并明确标记来源、类别及权利未决 | 将 KIT 作为已获许可的正式比赛训练/对外交付来源；再分发视频、关键帧或包含素材的演示；将发布 val 当作独立测试 |
| **Rathan v7** | 平台标 CC BY 4.0；保留的是同一 `BV6` 前缀的100张挖掘机 Idle **单帧框**，不是100个独立场景或连续动作区间。 | 保留隔离的静态辅助候选；使用时注明作者、项目、v7、许可证与处理方式 | 将单帧 Idle 当作时序真值；宣称原视频权利、独立视频数或对外模型/素材使用条件已全部查明 |

这里的“尚未放行”是本项目的证据门槛，不是对所有法域下使用行为作法律结论。历史 v1/v2 本地训练结果继续保留为探索性实验，**不据此推定数据许可已补齐**。

## KIT：许可与原视频来源

- [作者论文](https://publikationen.bibliothek.kit.edu/1000184499/165216818)第5页说明动作素材来自 YouTube 的 MegaMachinesChannel，第9页公开[数据包入口](https://drive.google.com/file/d/1tpdyE4Q-luAfED73M8Cq8rwTkZ6LOhZq/view?usp=sharing)，同页又写数据可向作者请求。2026-09-23 对论文所列 Drive 页面进行仅头部访问，返回 HTTP 200；**下载可达不等于获得再利用许可**。
- 论文页脚的 CC BY 4.0 标识属于论文；已保存的 ZIP 目录清单有8,355项，按 LICENSE、LICENCE、README、TERMS、CITATION、COPYRIGHT 名称检索未发现独立许可或使用说明。ZIP 已按既有用户指令删除，保留的304段及逐文件哈希见[KIT manifest](../Data_KIT/excavator_actions/manifest.json)。
- 论文没有列出每段3秒片段的原 YouTube URL、时间范围、原长视频 ID 或工地 ID。[YouTube 官方说明](https://support.google.com/youtube/answer/2797468?hl=en)区分默认标准许可与创作者主动选择的 CC BY；[YouTube 服务条款](https://www.youtube.com/t/terms)也不能被“视频公开可看”替代为独立再利用许可。本轮未查到这些原视频逐条所用的许可或视频权利人的书面授权。
- 原论文表1写挖掘机四类各75段，但当前作者包中 Swinging 为**79段**（val比其他类多4段）。额外的 `Swinging_076–079` 已生成[时间帧览图](../derived/supplemental_source_audit/KIT_Swinging_076-079_extra.jpg)供复核；画面看似回转，仍不能解释与论文计数不一致的来源原因。

**放行所需的外部证据**：作者/权利人说明 ZIP 的数据许可及比赛研究、模型权重、论文图和演示的允许范围；MegaMachinesChannel 素材的相应权利或授权依据；各片段原视频 URL、时间范围及同源分组。作者论文留有通讯作者邮箱，频道网站也列联系方式；本轮未向外部发送询问。

## KIT：类别语义与内部重复

- 按每类 train/val 的首、中、末位置抽取**6段，共24段**，每段8帧形成[Digging](../derived/supplemental_source_audit/KIT_Digging_contact_sheet.jpg)、[Dumping](../derived/supplemental_source_audit/KIT_Dumping_contact_sheet.jpg)、[Hauling](../derived/supplemental_source_audit/KIT_Hauling_contact_sheet.jpg)、[Swinging](../derived/supplemental_source_audit/KIT_Swinging_contact_sheet.jpg)四张时间帧览图；另放大检查了 Hauling/Swinging 的4段。所见 Digging 是取料动作、Dumping 在卡车上方卸料、Hauling 例子携料回转、Swinging 例子空斗回转，支持当前粗粒度映射。2013年[原始挖掘机动作研究](https://www.sciencedirect.com/science/article/pii/S1474034613000761)也将 hauling 描述为载料回转、swinging 描述为空斗回转。KIT 论文只列四个类别，未给逐片段的严格端点或满斗判定准则。**抽查不是304段全量语义认证，也不是新标签。**
- 对 KIT 每段现有8帧缓存共**2,432帧**做64位 DCT 感知哈希，两片段任意帧汉明距离≤8时记录候选近重复：[内部结果](../derived/supplemental_source_audit/kit_internal_similarity.json)有651对片段，其中**137对跨原发布 train/val**，9对跨划分的最小距离为0；还存在220对跨动作类。例：`Dumping_006`（train）与 `Dumping_072`（val）的[并排画面](../derived/supplemental_source_audit/KIT_train_val_nearframe_example.jpg) pHash 距离0，128像素缓存帧平均绝对像素差约0.36/255。它们足以否定“发布 val 是独立原视频集”的假设；跨类相似可能发生在动作交界，不能自动判为错标。
- ≤8近帧图形成22个多片段连通组，最大组153段，其中4组跨发布划分。连通组是**图像相似性审计结果，不是22段原视频或22个工地**。原始来源表仍缺失。现行[联合候选索引](../derived/joint_preflight/candidate_manifest.json)已把全部 KIT 放入单一训练候选来源组，未把 KIT val 当独立验证。

## Rathan：许可、Idle 含义与来源

- [Rathan 项目页](https://universe.roboflow.com/rathan/productivity-of-equipment-k83fo)明确标 CC BY 4.0，版本列表可见 v7 的4,814张导出图；本地保留的[原包 README](../Data_Rathan/idle_sources/README.dataset.txt)也写 v7、CC BY 4.0。[Roboflow 条款](https://roboflow.com/terms)对公开项目授予用户内容使用权并要求上传者声明具备授权；[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)要求署名、链接许可证并说明改动。这些是**平台层可核实条件**，不是已找到原视频版权人或逐帧授权链。
- 项目页没有数据来源说明。100张保留图的来源样式全为 `BV6-FRAMES`，编号84–2586、相邻编号间距中位数1；75张集中在84–300，抽看多个编号段都显示同一固定镜头、同一 Volvo 挖掘机。[帧号和扩大去重审计](../derived/supplemental_source_audit/audit.json)不能证明唯一原视频ID，但足以**不把100张计作100个独立场景**。
- 框类别是发布者的 `Excavator - Idle`；在连续编号的样例中挖掘机外观常静止、卡车可以移动，但 v7 对部分图片施加旋转/翻转等增强，且缺少原视频、FPS与时序区间，无法凭静态框确认“持续 Idle”。[相邻帧览图](../derived/supplemental_source_audit/Rathan_BV6_194-199.jpg)仅用于审查，不生成新标注。v2 中 Rathan 辅助也未改善原 Earthmoving 测试集的 Idle F1，故不把它升格为当前主训练的时序 Idle 来源。
- [另一 Roboflow 项目](https://universe.roboflow.com/ocr-national-id-card/productivity-of-equipment-k83fo-dam2j)同为2,006原图、同7个类别，但无发布数据版本；这是**疑似镜像**，无文件级同一性证明，不能额外计数。

**放行所需的外部证据**：原视频/帧素材出处与权利说明、`Idle` 的对象和时间定义；若再利用图片，保留作者与平台来源、v7、CC BY 链接及灰度/裁剪/增强说明。当前不能把它转成真实8帧视频。

当前可用的署名记录：**Rathan, “Productivity of Equipment”, Roboflow Universe, v7 (2024-05-18), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)**；本项目仅保留100张 `Excavator - Idle` 导出图及其COCO框，发布版本对图像做灰度、缩放、对比度处理并可能做随机增强。署名不替代对原视频素材来源的核查。

## 与 Earthmoving 的重复筛查边界

[扩大筛查](../derived/supplemental_source_audit/audit.json)取 KIT 视频约每秒1帧共901帧、Earthmoving 每5张取1张共17,818帧、Rathan 100张。64位 pHash 汉明距离≤8时：KIT↔Earthmoving 全集与 val/test 均0个候选（最小距离12）；Rathan↔Earthmoving 全集0个（最小14）；Rathan↔KIT 0个（最小16）。这排除了所抽样画面中的紧近似图像，**不能证明没有同一工地、同一原视频的不同时间段或镜头，也不能证明授权**。旧训练/测试划分保持不变。
