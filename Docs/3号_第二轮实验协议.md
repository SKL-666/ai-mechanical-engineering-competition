# 3号第二轮实验协议与入口

2026-09-23。执行用户授权的[第二轮原始计划（已执行）](archive/已完成计划/第二轮原始改进计划_2026-09-23_已执行.md)。全部实验仅使用本地Earthmoving、原始5类及XML框，无预训练、无新标签或补充数据。v1原始视频划分保持冻结；编号、端点与逐视频FPS的未决事项没有因本轮训练而自动解决。

## 执行协议

机器协议在[configs/round2_protocol.json](../configs/round2_protocol.json)，实验前保存副本到`experiments/03_action_recognition/20260923_round2/protocol.json`。UTC事件日志记录每次训练开始、完成、模型选择、测试前冻结以及测试执行顺序。后续测试集指标不能改变已冻结选择。

1. seed42、20epoch、每epoch960次抽样，执行S0～S6七个单帧对照。S0为按窗口抽样的控制；S1改为均匀抽原区间，再从其保守核心随机抽窗口；S2去掉类别加权。按S1/S2验证分数选择损失后，S3～S6分别检查96等比补边、128等比补边、亮度/对比度增强、窗口联合框和10%边距。S3～S6为明确的逐项变化链，不能把S6对S1的差异归因于单一因素。
2. 在S1～S6中选择验证集片段Macro-F1最高的预处理配置；S0保留作控制，主实验统一采用原区间采样。若区间采样没有胜过控制，必须如实报告，不宣称该调整已有效。
3. 固定同一预处理，40epoch、每epoch960抽样，比较`single_core`、`temporal_core`、`single_stream`、`temporal_stream`四种模型/训练输入组合。所有checkpoint均按同一85条验证片段的5类Macro-F1选择，最早最佳轮次优先。
4. 对4组seed42权重，在两段完整验证视频上使用固定64帧历史窗、基准8帧步长得到无标签推理概率。分别评价8/16帧更新步长×EMA alpha=1.0/0.5（共4种设置）。只按验证集连续逐帧Macro-F1选择部署组合及训练模式；每个模型的后处理参数在seed42验证结果上固定，不逐seed重调。
5. 写入`freeze.json`后，在所选训练模式下，为单帧与时序模型各补seed3407、2026。加上已有seed42，形成6次独立训练。完成训练后统一评价170条固定测试片段及两个完整测试视频；保存全部种子，不用测试分数挑选“最好seed”。样本标准差采用ddof=1。

本轮有7个有限预处理对照、4个主seed42组合和4个补充种子训练，共15次独立训练，其中6次进入冻结后的可比测试。训练预算相同指抽样数、更新次数和epoch相同；时序模型每样本读取8帧，计算量并不与单帧相等。

## 实现说明

- [round2_data.py](../earthmoving/round2_data.py)：新增`derived/earthmoving_round2/`，不改v1。train/val/test索引分文件；85/170个评价片段保留原sample_id和范围。两个模型都用末帧作输出目标；单帧读取末帧，时序模型在相同窗口均匀取8帧，含末帧。
- 流式训练索引以原视频全局64帧历史窗、8帧步长生成，仅当末帧已有一致标签、所属保守原区间可追溯且历史框完整时纳入。训练目标只有末帧，不把跨界窗口全部帧改为同一个动作。短于暖机范围的第一个区间可能没有流式目标；实际支持数单独保存。
- 原区间抽样有放回，等概率选原区间组，再选其内部窗口/流式候选。采样曝光逐epoch、原视频、原行号、类别保存到`sampling_exposure.csv`。类别加权为当前可用训练原区间组频率的平方根倒数、均值归一为1；无测试信息参与。
- [round2_model.py](../earthmoving/round2_model.py)：共享三层2D CNN和64维投影。单帧输出末帧；时序版本增加3个左侧补零的残差Conv1d，dilation=1/2/4，最后时间步输出5类。无BatchNorm、无未来帧、不是平均池化。共享空间骨干，时序头增加参数量，这不是严格参数量相等的消融。
- AdamW lr=0.001、weight_decay=0.0001，余弦退火到1e-5，梯度范数限制5。与上轮pilot相比，还改变了模型投影、末帧采样和训练预算；新模型与pilot的差异不能全部归因于时序。
- `letterbox`保持宽高比，用RGB128补边。增强仅训练启用；同一片段的所有帧共享亮度/对比度倍率0.85～1.15。联合框仅用当前历史窗已有的XML框，没有未来位置或动作标签；按宽高各扩10%并限制在图像内。

## 连续推理与评价

[round2_action.py infer](../scripts/round2_action.py)在独立进程中安装文件读取保护，禁止动作TXT、片段/流式标签索引和consensus真值。输入仅为帧、已有框与checkpoint。输出`probabilities.jsonl`保存固定网格上的5类分数，不按真值边界切片。支持`--tracks`读取挖掘机轨迹CSV，未提供该参数时标记XML_GT_PROTOTYPE_NOT_TEAM2。

[round2_continuous.py](../scripts/round2_continuous.py)的`render_predictions`只从概率及轨迹可用性生成动作段，段CSV写出后才读取真值计算评价。每次从可用时刻保持预测至下个决策点；缺框立即停止，间断后重置EMA。无工序规则纠错。首63帧暖机；本轮图像采样时滞为0。alpha0.5的EMA名义平均历史年龄为一个决策步长，但这不是实际动作切换延迟的严格上界，不能声称无额外延迟。

片段分类和连续逐帧指标分开。各类Precision/Recall/F1固定0～4顺序，零分母计0。连续指标另记录覆盖率、真值忽略和有真值但无预测的帧数。

由于真实端点仍有歧义，本轮**段级IoU/Edit采用显式遮蔽后的已知帧时间轴**：在每段连续有预测的范围内移除真值未知帧，保留顺序，再计算同类动作段一对一IoU匹配F1@0.1/0.25/0.5和归一化编辑分数；不跨越无预测间断拼接。它们不是完整精确真值边界上的标准成绩，名称、说明必须保留这一差别。评价概念参考[MS-TCN作者评价定义](https://github.com/yabufarha/ms-tcn/blob/master/eval.py)，本项目独立实现并加入未知标签处理，没有引入其训练代码或数据。

边界评价用“前一动作最后已知帧之后，到后一动作第一已知帧”的区间表达真值位置；不猜中点。按有向类别对、一对一最近匹配、容差16帧统计precision/recall，以及匹配边界到真值区间的距离。未知区域内无法评分的转变不计精确边界错误；覆盖与未匹配数另计。这仍是暂行评估协议，需与6号确认。

## 可复现命令

在项目根目录执行：

```bash
cd '/Users/mac/Project/AI+机械工程大赛'
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/run_round2.py
```

总入口保存每条子命令和日志，已完成的运行只有配置一致时才复用；既有训练目录不被覆盖。`--stop-after-freeze`可只执行到验证选择冻结阶段，不执行后续重复训练/测试。

独立入口示例（配置与checkpoint路径使用本轮实际产物，新输出路径必须尚不存在）：

```bash
.venv/bin/python scripts/round2_action.py train --config <已有配置.json> --out <新运行目录>
.venv/bin/python scripts/round2_action.py evaluate --checkpoint <best.pt> --subset val --out <新评价目录>
.venv/bin/python scripts/round2_action.py infer --checkpoint <best.pt> --video 104154 --out <新概率目录>
.venv/bin/python scripts/round2_continuous.py --inference <概率目录> --stride 8 --alpha 1.0 --out <新动作段及评价目录>
```

测试只用于方案冻结后的统一评价。已有pilot测试集曾被查看，不宣称本轮是全新的盲测。所有连续结果仍使用XML框，不等于真实检测跟踪联调；Move仍只有4条原始动作区间，三次随机种子不能增加场景独立性。
