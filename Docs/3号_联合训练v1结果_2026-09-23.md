# 3号：三来源训练 v1 结果

日期：2026-09-23。**本地 A/B/C 共9次独立训练已完成，验证选择先于本轮测试冻结。**本文保留 v1 原始结果；后续改进见[联合训练 v2](3号_联合训练v2改进与结果_2026-09-23.md)。补充来源的动作映射和使用权证据仍有未确认项，本记录是内部实验结果，不是对外数据/模型发布许可或真实轨迹联调证明。

## 输入与冻结协议

- 五类编号仍为 Idle、Swing Bucket、Load Bucket、Dump、Move；旧 Earthmoving 6/2/2 原视频划分和历史结果不变。新索引仅用 Earthmoving train 224 片段、KIT 304 段、Rathan 100 张 Idle 单帧；固定 Earthmoving val 85、test 170 片段。KIT 和 Rathan 均只作为训练候选，不沿用其发布划分评价独立场景。
- [协议](../configs/joint_training_v1.json)在测试前固定：A＝仅 Earthmoving，B＝每步8条 Earthmoving＋8条 KIT，C＝B＋4张 Rathan 单帧辅助。每组种子 42/3407/2026，从零训练同一时序模型，40 epoch、每 epoch 60 次更新、每次16条时序片段；各运行同为 2,400 次更新、38,400 条时序抽样。C 另有9,600次静态抽样及额外计算，辅助损失权重0.25。
- 时序输入是整帧 RGB 等比补边至128、固定8帧；Rathan 使用原发布框裁出的单帧，只监督共享空间编码器和分类头，**不伪装为运动视频**。相较第二轮的设备框裁剪，预处理已改变，因此不能把新旧轮分数差全归于新增数据。
- 每次运行按同一85条验证片段的五类 Macro-F1 选最早最佳轮；9个选中 epoch 和权重 SHA 写入[测试前冻结](../experiments/03_action_recognition/20260923_joint_v1/freeze.json)。训练日志、源码快照、原件索引/缓存哈希与完整CSV在[实验目录](../experiments/03_action_recognition/20260923_joint_v1/)。

精确值及9个测试预测、逐类支持和混淆矩阵见[测试汇总](../experiments/03_action_recognition/20260923_joint_v1/test_evaluation/summary.json)与同目录各运行文件。原测试集在之前实验已被查看，本轮不称“新盲测”；本轮没有按测试分数选择权重或组别。九次测试的 Move 片段 support 均为1、F1均为0。测试 Idle F1 的三种子平均值：A 0.048、B 0、C 0；本轮 Rathan 静态 Idle 辅助未改善原域 Idle。

连续推理采用固定64帧历史窗、8帧步长、无EMA；每组仅用**验证片段 Macro-F1 最高的种子**（A s42、B s3407、C s3407），选种规则及模型哈希在[连续测试选择记录](../experiments/03_action_recognition/20260923_joint_v1/continuous_test/selection_before_continuous_test.json)。概率只由帧、XML真值框的轨迹可用性和权重产生；动作段写出后才读取真值评价。[连续测试汇总](../experiments/03_action_recognition/20260923_joint_v1/continuous_test/summary.json)的两段原视频合并逐帧 Macro-F1：A **0.198**、B **0.210**、C **0.177**；覆盖率均约99.62%。B 的这一单种子连续指标略高，但三种子片段均值较低，不能认定稳定改善。段F1/Edit沿用遮蔽未知真值帧的口径，并非精确全边界成绩。仍未接入2号真实轨迹。

## 解释与下一步

本轮充分执行了冻结协议，但**没有证据支持把 B/C 替代 A 作为更好的通用动作模型**。补充集对原域 Move 不提供标签；Rathan 是与视频域差异明显的单帧框；KIT 片段的原长视频/工地分组未知。A 自身三种子波动也较大。应保留所有负向结果，先查跨域外观与动作语义、来源分组，再设计下一版对照；不得围绕已查看测试集反复调参。

[作者论文](https://publikationen.bibliothek.kit.edu/1000184499/165216818)公开 KIT 来源包链接，说明素材来自公开 YouTube 视频；论文开放许可不能自动覆盖这些视频的使用或再分发。KIT 包内无独立数据许可证，需取得使用条件依据。[Rathan 项目页](https://universe.roboflow.com/rathan/productivity-of-equipment-k83fo)标 CC BY 4.0，但原视频素材授权链仍未核实。上述权利问题不由一次本地训练解决。KIT Hauling/Swinging→Swing Bucket 及 Digging/Dumping 映射也仍是[预处理配置](../configs/joint_preflight_mapping.json)中的暂定规则，不能作为全部片段已被人工确认的结论。

测试目录中的 FPS 仅计**已缓存片段张量读取与模型前向**，不含原视频解码、检测/跟踪；连续推理记录另含 JPEG/补边/前向，但仍不含检测/跟踪或真实系统延迟，二者不能混用。
