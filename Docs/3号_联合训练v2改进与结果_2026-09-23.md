# 3号：联合训练 v2 改进方案与执行结果

日期：2026-09-23。v2 针对[v1 的失败模式](3号_联合训练v1结果_2026-09-23.md)制定并已执行：**A/B/C 各3个种子、共9次完整训练**，全部完成后才冻结验证选择并一次性运行本轮片段与连续测试。原5类、Earthmoving 冻结划分、KIT/Rathan 原件、候选索引和 v1 结果均未改动。补充来源的[后续语义、许可和来源核验](3号_KIT与Rathan语义许可来源核验_2026-09-23.md)明确了 KIT 发布划分近帧交叉及对外使用仍缺的证据。

## 事先固定的改进

1. **缓和主域被稀释**：v1 B/C 每步从 Earthmoving/KIT 各取8条；v2 改为12/4。A 保持16条 Earthmoving，作为同训练策略下的主域对照。
2. **适度增加稀缺类曝光**：每个来源内部先按 `sqrt(该类候选片段数)` 抽类别，再在该类中均匀抽片段。Earthmoving 的预期抽样份额由原始频率 `[5.4%,46.9%,24.6%,22.3%,0.9%]` 调为约 `[11.7%,34.6%,25.0%,23.9%,4.8%]`，类别顺序为 Idle、Swing Bucket、Load Bucket、Dump、Move。此举重复现有片段，**没有创造新 Move 场景或标签**。
3. **减弱静态图像干扰**：C 的 Rathan 辅助从每步4张、损失权重0.25改为2张、权重0.05；单帧仍只监督共享空间编码器和分类头，不当作真实时序视频。

[固定协议](../configs/joint_training_v2.json)保留与v1相同的时序模型、整帧128补边、8帧输入、AdamW、40 epoch×每轮60次更新、每步16条时序片段及种子42/3407/2026。每次运行同为2,400次更新与38,400条时序抽样；C另有4,800次静态抽样和额外计算。按同一85条 Earthmoving 验证片段五类 Macro-F1 选最早最佳轮，9个权重及哈希见[测试前冻结](../experiments/03_action_recognition/20260923_joint_v2/freeze.json)。训练复用v1已核哈希的 Earthmoving 输入缓存；每次运行另存源码快照和配置。

## 解释与下一步

v2 的协议和模型选择在**本轮测试执行前**冻结，但方案制定时已看过 v1 在同一测试集上的结果；因此以上是**已复用测试集上的探索性对照**，不能当作新的独立泛化证明。当前可保留 B/C 为内部研究候选，不能依测试分数挑最好权重宣布部署版。补充来源的原视频/工地独立性、KIT动作语义和数据使用条件仍需确认；Rathan静态 Idle 没有改善目标域 Idle。

下一次有价值的验证是取得独立新工地/视频及现成 Idle、Move 标签，先核来源、许可和5类语义，再按原视频分组留出新场景测试；若无新数据，应优先复核错误样例及2号真实轨迹接口，停止围绕已查看的原测试集反复调参。[训练事件](../experiments/03_action_recognition/20260923_joint_v2/events.jsonl)、[评价源码快照](../experiments/03_action_recognition/20260923_joint_v2/evaluation_code_snapshot/manifest.json)和两份测试汇总保留所有正负结果。片段测试 FPS 只覆盖缓存输入与模型前向；连续推理另含JPEG读取/补边，二者都不含检测跟踪或完整系统延迟。
