# 3号阶段复盘与数据扩充判断

更新：2026-09-23。数值以[第二轮结果](3号_第二轮改进结果_2026-09-23.md)和[逐种子CSV](../experiments/03_action_recognition/20260923_round2/final_per_seed.csv)为准；这里仅保留结果解释与后续实验原则。

## 已有结果能说明什么

- 第二轮时序平均优于同轮单帧，但片段分数低于 pilot，连续均值略升且波动较大；**没有稳定的整体提升**。同一预选模型的连续验证 Macro-F1 为 50.29%，测试为 25.09%。这是泛化风险信号，原因尚未确定。
- pilot 与第二轮同时改变网络、采样、末帧目标和训练预算。没有新增数据的同条件对照，不能把退步全部归因于“数据少”或某一个改动；普通 CE 在当前有限预算胜出，也不证明其他方法普遍无效。
- Move 的独立区间和测试支持极少；重复采样相邻帧或三次种子训练不增加独立场景。计算耗时不等于完整系统延迟，XML真值框离线回放也不等于2号真实轨迹联调。
- 测试集已经查看，后续原域对照仍可报告，但不得重新称为盲测。测试前冻结见[freeze.json](../experiments/03_action_recognition/20260923_round2/freeze.json)。

## 数据扩充判断

优先价值来自**新工地、设备、视角下的独立视频**，以及带现成标签的 Move、Idle。更多窗口只能改变训练曝光；只有检测框而没有动作语义的图片不能直接充当动作监督样本。新来源必须核对设备对象、动作语义、时间轴、原视频/工地、许可和与 Earthmoving 的重复，不能猜映射或把未知标成 Idle。新增训练数据可能改善模型；独立验证和测试数据则主要改善选模与评价可信度，分数不保证提高。

Rathan/KIT 的隔离接收、尚缺 Move、暂定映射与数据边界见[联合训练前准备](3号_三数据集联合训练前准备_2026-09-23.md)。后续 A/B/C 已执行两轮：v1 未观察到收益；[v2](3号_联合训练v2改进与结果_2026-09-23.md)在已复用测试集有探索性改善，但 Idle/Move 仍为0。外部其他来源的证据级别见[数据集检索](3号_挖掘机动作数据集补充核验_2026-09-23.md)。

## 后续对照原则

本地 A/B/C 的 v1、v2 固定模型、更新预算、种子和选模规则均已冻结并执行，最新见[联合训练 v2](3号_联合训练v2改进与结果_2026-09-23.md)。下一版如能取得可靠的原视频/工地分组，应先划分再切窗，并在训练前留出独立新场景测试集；原 Earthmoving 测试集保持原样。继续报告全部种子、逐类 support、逐视频和连续指标、耗时、无效与退步结果，不凭最好种子或原域总体 Accuracy 宣称问题已解决。放行顺序维护在[会话交接](会话交接_3号任务推进.md)。

研究背景：[Sun等，ICCV 2017](https://openaccess.thecvf.com/content_iccv_2017/html/Sun_Revisiting_Unreasonable_Effectiveness_ICCV_2017_paper.html)与[Cui等，CVPR 2019](https://openaccess.thecvf.com/content_CVPR_2019/html/Cui_Class-Balanced_Loss_Based_on_Effective_Number_of_Samples_CVPR_2019_paper.html)讨论数据规模与样本重叠；其任务和规模不同，不能外推本项目会提高多少分。
