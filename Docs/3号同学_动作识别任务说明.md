# 3号同学：动作识别任务说明

本说明依据[组内实验设计与结果提交规范](../指导/工序步骤正确性视觉感知系统_实验设计与结果提交规范.md)及原始[动作说明](../Data/doc.txt)，固定3号职责、5类和交付接口。进展见[会话交接](会话交接_3号任务推进.md)，运行方式见[训练入口](Earthmoving_训练入口方案.md)。

## 职责与边界

3号从连续帧和设备轨迹构建片段，识别动作并输出按设备排序的时间段。1号维护统一数据与划分；2号提供检测框和跟踪ID；4号据动作序列判断工序异常；5号集成系统；6号汇总实验。3号提交动作预测、置信度、模型和复现信息，不根据预设正常工序改写预测。

独立动作实验可用真值设备框和真值动作区间预切片段，但须标明这种输入条件。连续视频联调必须使用固定推理窗口与2号预测轨迹；**测试集真值动作边界只用于评价，不触发预测或平滑**。模型计算耗时、窗口等待与完整系统延迟分别报告。

## 原始5类

| ID | 原始英文 | 接口标识 | 含义 |
|---:|---|---|---|
| 0 | Idle | `idle` | 等待/空闲 |
| 1 | Swing Bucket | `swing_bucket` | 铲斗回转 |
| 2 | Load Bucket | `load_bucket` | 铲斗装载/挖掘取料 |
| 3 | Dump | `dump` | 卸料 |
| 4 | Move | `move` | 整机移动 |

接口标识不改变原类别语义或编号。Move 不解释为“提升”，Swing Bucket 不拆为“载料回转/返回”；未知不补成 Idle，跟踪中断和低置信度可作状态标志。补充数据仅能在核实语义、许可和来源后按原5类纳入，见[联合训练前准备](3号_三数据集联合训练前准备_2026-09-23.md)。

## 实验与提交

在同一冻结测试集和同一评价单位下比较 baseline 与最终模型，提交 Accuracy、Precision、Recall、Macro-F1、FPS、逐类 Precision/Recall/F1/support、按 ID 0～4 排列的混淆矩阵，以及逐样本预测。明确片段级与逐帧指标、零分母处理、真值框或预测框、FPS计时范围。独立训练使用预先确定的种子并如实报告全部结果；重复测试同一权重不算独立训练。条件性鲁棒性测试须说明真实场景或合成扰动；无数据则记“未测试”。

每个正式运行另存目录，不覆盖历史结果：

```text
experiments/03_action_recognition/<run_id>/action_recognition/
├── metrics.csv
├── class_metrics.csv
├── confusion_matrix.png
├── predictions.csv
├── config.yaml
└── README.md
```

核心 CSV 表头：

```csv
model,accuracy,precision,recall,macro_f1,fps
class,precision,recall,f1,support
video_id,start_time,end_time,true_action,pred_action,confidence
```

上面三行分别属于 `metrics.csv`、`class_metrics.csv`、`predictions.csv`，不能合并为一份文件。逐类顺序为 `idle,swing_bucket,load_bucket,dump,move`。真实边界预切的分类结果不能当作自动动作分段能力证据。

连续联调另交 `action_segments.csv`：

```csv
video_id,equipment_id,start_frame,end_frame,start_time,end_time,pred_action,confidence
```

帧和秒区间均为左闭右开，帧从0开始；确认原始编号与FPS后按 `frame/fps` 换算时间。此文件由预测产生，不含 `true_action`。

`config.yaml`和运行README应记录数据版本及划分哈希、标签映射、帧/FPS依据、采样与裁剪、模型和预训练权重来源、训练参数与种子、推理窗口和平滑、评价口径、硬件与依赖、运行命令、权重路径及SHA-256。本地不是Git仓库，保存代码快照与哈希，不编造commit。

## 数据规则与验收

先按原视频/可核实来源分组划分，再切片段；同源裁剪和增强版本不得跨训练、验证、测试。阈值、模型和后处理只由训练/验证决定。Earthmoving 的编号、端点和时间基准仍有待确认项，详见[本地核查](Earthmoving_本地数据核查记录.md)；原 `Data/`、冻结划分和历史实验不改。Move 原始动作区间仅4条，报告其真实support及限制。

完成标准：5类与划分口径经团队确认；同测试集的模型结果、配置和原始预测可追溯；连续输入能产生按设备组织的动作序列供4/5号消费；明确哪些结果基于真值框，哪些基于真实预测轨迹。当前完成程度以[交接](会话交接_3号任务推进.md)为准。
