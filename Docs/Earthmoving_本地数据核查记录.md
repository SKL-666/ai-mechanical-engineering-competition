## 2. XML设备框、缺帧和重复图像

全部XML对象检查了ID、帧号、重复帧、坐标有限性、面积、越界和缺帧；挖掘机每视频均为ID=1，跨视频键为`(video_id,equipment_id)`。有效挖掘机框89,058条，无非法或越界框；缺8帧：143110/0、150625/0、152129/0～4、153004/0。读取器不补框、不插值。

已目视检查[10视频框示例](../experiments/01_dataset/xml_bbox_contact_sheet.jpg)，未逐帧人工核查全部框。卡车XML结构检查不代表其动作标签已完整验证。

两组跨视频完全相同首帧为143110/0 ↔ 150625/0、151341/0 ↔ 153004/0。v1分类片段/窗口排除全部4处；第二轮连续历史输入允许无动作监督的帧，其实际输入已检查无跨划分重复图像。未据此宣称近重复或工地级去重完成。

## 3. 编号与端点：未确认事项和当前规则

JPG/XML从0开始，TXT起始编号及端点开闭没有发布者明示。部分TXT终点等于图像帧数；469处相邻区间边界中468处相差1，153004第一处共用371。此现象支持闭区间习惯，但不足以确认编号基准。

143110标签结束于8491而图像到8516，152129从2开始。152129的note称末行曾从`5854 6011 2`改为`5854 6031 2`，当前实际标签仍是前者，图像最大编号6011；不按附注延长区间。

原始`(s,e,c)`分别检查四种解释并转换到0起始、左闭右开：

| 候选解释 | 转换区间 |
|---|---|
| 0起始、闭区间 | `[s,e+1)` |
| 1起始、闭区间 | `[s-1,e)` |
| 0起始、半开区间 | `[s,e)` |
| 1起始、半开区间 | `[s-1,e-1)` |

仅保留四候选一致且非缺失/冲突的标签，共88,075帧一致、991帧忽略。未知不补Idle，负值是忽略状态而非第6类。原始文件、行号和端点保留；没有按测试分数反选偏移。该规则是保守实验处理，不是确认作者端点语义。

v1每条原区间选最长连续可用核心，再取分类窗口，479条均保留样本。第二轮连续训练只监督固定历史窗的末帧，目标未知或历史框不完整则跳过；历史帧可跨动作边界。具体生成规则与逐组支持数分别见[第二轮协议](3号_第二轮实验协议.md)和[round2索引清单](../derived/earthmoving_round2/manifest.json)。

## 4. FPS与划分边界

25 FPS依据为2026-09-23查询到的[论文发布方Ground truth data检索摘要](https://www.sciencedirect.com/science/article/abs/pii/S0926580518308525)，该摘要同时说明480×272和10段视频。直读论文返回403，本地没有视频时间戳可验证是否曾抽帧。因此记录为“发布方摘要依据，本地节奏未独立核实”；秒列按25FPS条件化，帧索引保留。

已先按原视频本地冻结6/2/2划分，再生成派生数据；三组覆盖5类，Move原区间为2/1/1。视频名单及哈希以[split.json](../derived/earthmoving_v1/split.json)为准。仍待1/6号认可；原视频互斥不等于工地独立，论文6个项目的video-to-project映射尚未确认。
