证据分层：

- **A：读取到数据文件。**现有本地Earthmoving；新增KIT已读完整ZIP中央目录、8个标签样例和一个MP4，不代表完整数据包全部校验完毕。
- **B：发布页确认动作标签、许可及至少一个版本。**Roboflow的20个项目属此层。已实际点击ExcaActivities的COCO导出，出现登录要求；没有注册、登录或付费。其他项目不能声称已逐个成功下载。
- **C：有动作线索，但申请限制、缺原视频、无发布版本、链接状态不明或仅论文描述。**保留以减少漏检，不冒充可用数据。
- **D：任务不匹配。**只有物体类别、关键点、连续控制量、销售/遥测信息或空仓库。

“全平台”采用尽可能广的跨平台检索，不是对互联网所有资源的穷尽保证。各平台搜索索引、登录墙、失效分享及未索引资源仍可能造成遗漏。

## 2. 新增 KIT 数据集：文件级核验

### 来源和公开入口

- 论文：Bobo Helian、Gen Huang、Marcus Geimer，*Temporal sequence-based object detection and action recognition for mobile machinery on construction sites*，Advanced Engineering Informatics 68 (2025) 103691。[作者机构全文](https://publikationen.bibliothek.kit.edu/1000184499/165216818)、[DOI](https://doi.org/10.1016/j.aei.2025.103691)。
- 第9页 `Research elements` 明确链接 [Datasets.zip](https://drive.google.com/file/d/1tpdyE4Q-luAfED73M8Cq8rwTkZ6LOhZq/view)。同页通用 `Data availability` 又写需申请，两处不一致；**当前匿名文件访问成功是直接的可获取性证据**。
- 实测压缩包5,815,544,519字节，约5.82 GB / 5.42 GiB。网页显示5.4G。
- 论文为CC BY，但ZIP内没有README、LICENSE或授权文档；不能把论文许可自动套给视频。当前结论是“公开可下载、有现成标签”，不是“已核实可任意再分发”。

### 重要边界

1. 论文表1统计600段、2,680/320关键帧；实际公开包单机械视频604段、2,760/240关键帧。多机械论文表2的关键帧和划分也不能直接当成下载包事实。实验必须以最终清单为准。
2. 多机械文件夹内只看到MP4，没有配套逐对象动作标签；名为 `Multi-machine multi-action dataset` 的子目录为空。不能把这300段直接纳入有多对象真值的动作检测训练。
3. 全包只见JPG/TXT/MP4和目录，没有CSV/JSON/pbtxt等连续时序标注文件。已确认的是按动作分组的片段与关键帧框标注；未确认长视频逐帧动作区间。
4. 图片和视频的原始train/val划分边界不同。不能将其分别读取后直接拼成一个评估集；需按源视频/采集源统一划分、查重。
5. 本次只下载一个619,852字节的 `Swinging_003.mp4`，成功完成ZIP条目读取和CRC检查，未进行完整视频解码或全部样本人工质量检查。
6. KIT挖掘机4类不能补齐Earthmoving的Idle、Move。Hauling/Swinging与Earthmoving合并回转标签的语义映射需进一步看样例核实，不能立即改变本项目既定5类。

## 3. Roboflow：27个动作标签项目的逐项核查

详见[完整Roboflow清单](Roboflow_动作标注候选_2026-09-22.md)。全部27个项目的主页均通过浏览器直接查看过动作类别、图片量、版本数和许可。

注意三点：

- Roboflow标为 `Object Detection` **不一定只是机械检测**。若框类别本身是Digging/Dumping等，就是动作类别框，符合“有动作标注”；但不等于有连续时序标签。
- 搜索页、项目原始图数和某个增强版本图数可能不同。例如cvclass原始40张，而模型关联版本可显示104张，不能按104张独立图计算。
- 27个项目不代表27套相互独立的新数据。Yitta两项目同作者、同3,048张、同类别，疑似复用；`excava`与`excavadoras`也可能有关联。当前只是同源风险提示，未通过图像哈希证明重复。应对全部候选和Earthmoving去重后再划分。
