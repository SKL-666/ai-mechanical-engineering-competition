# 补充数据接收与校验

更新：2026-09-23。本文记录 Rathan v7 与 KIT 原包的来源、完整性和精简结果；后续本地训练最新见[联合训练 v2 结果](3号_联合训练v2改进与结果_2026-09-23.md)。媒体深度审计与候选映射见[联合训练前准备](3号_三数据集联合训练前准备_2026-09-23.md)。Earthmoving 原件和冻结划分未改。

## Rathan v7 COCO

原包 `Productivity of Equipment.v7i.coco.zip` 为 **241,713,848 字节**，SHA-256 `229e7700cae14f3be9adcdbf13d784151b1e47b5a82aafea95a743aa6af7782a`；ZIP 校验通过。包内 README 指向 [Rathan 项目](https://universe.roboflow.com/rathan/productivity-of-equipment-k83fo)，平台标 CC BY 4.0。导出为 480×280 灰度、对比度处理的 COCO，部分图像经翻转、裁剪、旋转；原视频素材授权链未核实。

实包有 **4,814 JPG**、train/valid/test 三份 COCO JSON（4,212/401/201 图；9,949/957/478 框）。去除 Roboflow 增强后缀后共 **2,006 个来源文件名**，其中 1,404 个各有 3 张版本；来源名未跨发布划分，但 `BV6-FRAMES`、`V7-FRAMES` 前缀均跨划分，不能视作独立视频测试。各框类总数：

| 框类 | 框数 |
|---|---:|
| DumpTruck - Idle / Loading / Moving | 4,007 / 166 / 473 |
| Excavator - Bucket Load / Bucket Unload | 1,052 / 875 |
| Excavator - Idle / Working | 246 / 4,565 |

Excavator - Idle 的 246 框来自 **100 个去增强重复的来源名**，已保留一份确定版本的原图字节、原框和来源映射于[精简清单](../Data_Rathan/idle_sources/manifest.json)。它们是静态检测标注，不提供连续 Idle 时段；DumpTruck - Moving 不是挖掘机 Move，Bucket/Working 类的语义未放行。原包现已删除。

## KIT

作者论文提供 [Datasets.zip 下载入口](https://drive.google.com/file/d/1tpdyE4Q-luAfED73M8Cq8rwTkZ6LOhZq/view)；匿名请求曾返回 HTTP 206。下载原包 **5,815,544,519 字节**，SHA-256 `af7b54188b3eb80bd22fea55210254bf0ba0dd7dda889540a3958b72ec0f02e3`；8,355 条目的 ZIP CRC 检查无错误。整包含 2,304 MP4、3,000 JPG、3,000 TXT，不能把全部 MP4 算作挖掘机动作片段。

按目录提取的 **304 段挖掘机 MP4** 共 818,324,161 字节：Digging 75、Dumping 75、Hauling 75、Swinging 79；发布 train/val 分别为 236/68。每文件哈希见[KIT 清单](../Data_KIT/excavator_actions/manifest.json)，304 段后续全部逐帧解码成功。目录标签为预切片段，无 Idle/Move；原长视频和工地分组未知，不能直接沿用发布 val 或把动作名当作本项目语义。包内未见独立数据许可证，论文开放许可不自动覆盖视频使用或再分发。原包现已删除。

## 清理和追溯

用户授权删除不需要的补充数据后，仅删除上述两个完整 ZIP，合计 **6,057,258,367 字节**。删除前复核原包、304 段视频、100 张原图和 404 份派生缓存哈希；Rathan 精简前后缓存字节一致。保留[两来源原件清单](../derived/joint_preflight/cleanup_record.json)所列 KIT 视频、Rathan Idle 原图/COCO、[候选索引](../derived/joint_preflight/candidate_manifest.json)和缓存。完整删除路径、原 SHA 与核验结果见该清理记录；从保留原件可重建候选索引与缓存。
